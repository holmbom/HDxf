**Steg 9.2 (facit `doc/facit/fas9_existing_fields.scr`, AutoCAD 2025:s kärna, 2026-10-28).** Hörn-id: AutoCAD skriver 91 på LWPOLYLINE
efter hörnets punkt (10, 20) och på VERTEX efter punkten (10, 20, 30), bara på de hörn som har ett id (`AUTOCONSTRAIN` ger alla hörn id 1, 2, 3 …; ett
hörn som en CHAMFER lägger till har inget; `PEDIT _Reverse` låter id följa hörnet; `BREAK` tar bort hörnet mellan brytpunkterna och lämnar de andras id).
Polylinjens flaggor (70) är 1 (sluten) eller 0 i alla dessa filer: **ingen flagga 1024**, så 91 är inte knutet till den. Före 2010 (R12, 2000, 2004, 2007) har
ingen post något 91. Filerna: `acad_<version>_dxf_vertexids{,_reversed,_chamfered,_collinear,_broken,_heavy}[_bin].dxf`, R12 och 2000 … 2018 (84 filer), första
LWPOLYLINE `vertexids` handle `24F`, POLYLINE med VERTEX-id i `vertexids_heavy` (`CONVERTPOLY _Heavy`). **Ej testat:** flaggan 1024 (AutoCAD skriver den
inte här; ingen gren att prova), hörn-id på 3D-polylinjer och polygonnät (kärnan har ingen kommandosekvens som ger dem id), id vid tillägg av hörn med
PEDIT (kärnan har inga synliga hörn att redigera).
